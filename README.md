# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг.

## Функционал

* Добавление книг с оценкой
* Просмотр списка всех книг
* Статистика по авторам
* Средняя оценка всех книг
* Удаление книг

## Как использовать

### Добавление книги
1. Выберите пункт 1 в меню
2. Введите автора, название, оценку (1-5) и дату прочтения

### Просмотр книг
* Пункт 2 - полный список книг
* Пункт 3 - средняя оценка
* Пункт 4 - статистика по авторам

### Удаление книги
* Пункт 5 - выбор книги для удаления по номеру

## Пример работы:

2 Показать все книги
