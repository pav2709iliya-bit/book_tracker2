# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг.

## Как запустить
1. Скачайте проект.
2. Установите Python.
3. Выполните: `python main.py`
## Пример работы

1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
